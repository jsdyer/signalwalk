Reading a walk

A cell change marks consecutive observations with different known serving cells in the same technology, SIM slot and serving role. Phone-state rows show the fields Android reported. Many devices provide a network domain, technology or reject cause without an explicit registration state. An empty interval or weak signal alone cannot establish loss of registration.

The JSON report contains relative timing, radio measurements, change flags and recognized phone-state fields. It omits coordinates, original timestamps, filenames, identifiers and your checkpoint names.
